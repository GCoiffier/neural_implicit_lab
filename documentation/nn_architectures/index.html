SirenNet(dim_in, dim_hidden, n_layers, dim_out=1, w0=6.0, w0_first_layer=30.0, residual=False, init_type='siren', activation_type='siren')

Bases: ImplicitModel

Implementation of a SIREN network, that is a multilayer perceptron with periodic activation functions [1].

Alongside the base implementation from [1], several improvements published over the years are also available. They consist of either an initialization scheme, or a different activation function.

Activation functions available are
  • "siren": the original SIREN activation [1]
  • "finer": sin((|x|+1)x) activation proposed by FINER [2]
  • "lsa": learnable spectral activation [3]
  • "id" : identity (no activation, usually used in the last layer)
Initialization schemes available are
  • "siren": the original SIREN initialization scheme [1]
  • "geometric": geometric initialization scheme [4]
  • "mfgi": multi-frequency geometric initialization scheme [5]
  • "winner": initialization proposed by WINNER [6]
References

[1] Implicit Neural Representations with Periodic Activation Functions, Sitzmann et al., 2020
[2] FINER: Flexible spectral-bias tuning in Implicit NEural Representation by Variable-periodic Activation Functions, Liu et al., 2023
[3] Learnable Spectral Activations, Shor et al., 2026 [4] DiGS : Divergence guided shape implicit neural representation for unoriented point clouds, Y.Ben-Shabat et al., 2022
[5] Improving Accuracy and Efficiency of Implicit Neural Representations: Making SIREN a WINNER, H.Chandravamsi et al., 2026

Lipschitz Architectures

Lipschitz neural networks are neural networks where the Lipschitz constant is controlled (equal or inferior to a given value). Recall that a function \(f\) is \(K\)-Lipschitz if for any points \(x,y \in \mathbb{R}^n\), we have:

\[|f(x) - f(y)| \leqslant K\,||x -y||.\]

The signed distance function is notoriously a 1-Lipschitz function, and using 1-Lipschitz neural implicit enables SDF approximations with guarantees as well as the use of different loss functions (see for instance the hKRTrainer class).

DenseLipAOL(dim_in, dim_hidden, n_layers, dim_out=1, coeff_lip=1.0, activation=nn.ReLU())

Bases: ImplicitModel

Neural network made of Semi-Definite Programming neural layers, as proposed by [1]. Using a square matrix \(W \in \mathbb{R}^{k \times k}\) and a bias vector \(b \in \mathbb{R}^k\), each layer is defined as:

\[x \mapsto \sigma(WT^{-1/2}x + b)\]

where \(T\) is a diagonal matrix of size \(\mathbb{R}^{k \times k}\):

\[ T_{ii} = \sum_{j=1}^k \left| (W^T W)_{ij}\right|\]

and \(\sigma(x) = \max(0, x)\) is any 1-Lipschitz function.

References

[1] Almost-Orthogonal Layers for Efficient General-Purpose Lipschitz Networks, Prach and Lampert, 2022

DenseLipCPL(dim_in, dim_hidden, n_layers, dim_out=1, coeff_lip=1.0, activation=nn.ReLU(), with_group_sort=True)

Bases: ImplicitModel

Neural network made of Convex Potential layers, as proposed by [1]. Using a square matrix \(W \in \mathbb{R}^{k \times k}\) and a bias vector \(b \in \mathbb{R}^k\), each layer is defined as:

\[x \mapsto x - \frac{2}{||W||_2} W^T \sigma(Wx + b)\]

where \(\sigma(x) = \max(0, x)\).

References

[1] A Dynamical System Perspective for Lipschitz Neural Networks, Meunier et al., 2022

DenseLipSDP(dim_in, dim_hidden, n_layers, dim_out=1, coeff_lip=1.0, activation=nn.ReLU(), with_group_sort=True)

Bases: ImplicitModel

Neural network made of Semi-Definite Programming neural layers, as proposed by [1]. Using a square matrix \(W \in \mathbb{R}^{k \times k}\), a bias vector \(b \in \mathbb{R}^k\) and an additional vector \(q \in \mathbb{R}^k\) as parameters, each layer is defined as:

\[x \mapsto x - 2WT^{-1} \sigma(W^Tx + b)\]

where \(T\) is a diagonal matrix of size \(\mathbb{R}^{k \times k}\):

\[ T_{ii} = \sum_{j=1}^k \left| (W^T W)_{ij} \,\exp(q_j - q_i) \right|\]

and \(\sigma(x) = \max(0, x)\) is the rectified linear unit (ReLU) function.

References

[1] A Unified Algebraic Perspective on Lipschitz Neural Networks, Araujo et al., 2023
[2][https://github.com/deel-ai/orthogonium/blob/main/orthogonium/layers/conv/SLL/sll_layer.py](https://github.com/deel-ai/orthogonium/blob/main/orthogonium/layers/conv/SLL/sll_layer.py)
