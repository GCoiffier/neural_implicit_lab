    TrainingConfig(BATCH_SIZE=100, TEST_BATCH_SIZE=5000, N_EPOCHS=100, LEARNING_RATE=0.001, DEVICE='cpu', OPTIMIZER='Adam', NUM_DATALOADER_WORKERS=-1) dataclass

    Configuration object storing hyperparameters for a Trainer class.

    Attributes:

    Name Type Description
    BATCH_SIZE int

    Number of samples per batch in the training data loader. Defaults to 100.
    TEST_BATCH_SIZE int

    Number of samples per batch in the test data loader. Defaults to 5000.
    N_EPOCHS int

    Number of passes over the training dataset. Defaults to 100.
    LEARNING_RATE float

    Learning rate given to the optimizer. Defaults to 1e-3.
    DEVICE str

    Torch device on which training runs ("cpu", "cuda", ...). A warning is emitted if set to "cpu" while a GPU is available. Defaults to "cpu".
    OPTIMIZER str

    Name of the optimizer (case-insensitive). One of "adam", "sgd", "muon", "adabound", or "custom". If "custom" is selected, the user must set trainer.optimizer before calling the train method). Unknown names fall back to Adam. Defaults to "Adam".
    NUM_DATALOADER_WORKERS int

    Number of worker processes for the train data loaders. -1 means torch.get_num_threads(). Defaults to -1.

    Trainer(config)

    Base trainer class. Implements the optimization loop for a given neural implicit model.

    This class is not meant to be used directly, but to be inherited from. Subclasses need to implement the abstract methods forward_train_batch and forward_test_batch.

    Attributes:

    Name Type Description
    config TrainingConfig

    The training hyperparameters.

    Loader over the training data. Set by set_training_data.
    test_data_loader DataLoader

    Loader over the test data. Set by set_test_data.
    optimizer Optimizer

    The optimizer. Built at the start of train, unless OPTIMIZER is "custom", in which case it must be assigned by the user.
    scheduler LRScheduler

    The learning rate scheduler, if any (see add_scheduler).
    callbacks list[Callback]

    Callbacks called at different steps of the training loop.

    get_optimizer(model)

    Builds the optimizer described by config.OPTIMIZER, with learning rate config.LEARNING_RATE:

    • "adam": torch.optim.Adam. Also used for unknown names.
    • "sgd": torch.optim.SGD with momentum 0.9.
    • "muon": Muon on weights of dimension >= 2, and Adam (lr 5e-4) on biases and gains. Weight decay 0.01.
    • "custom": no optimizer is built.

    step_scheduler()

    Steps the learning rate scheduler, if any. Prints the new learning rate when it changes.

    train(model, starting_epoch=0)

    Runs the optimization loop for config.N_EPOCHS epochs.

    If some were added, callbacks are invoked during training:

    • callOnBeginTrain before the first epoch;
    • for each epoch: callOnBeginEpoch, callOnEndForward after each batch, callOnEndEpoch, then the scheduler is stepped and the model is evaluated on test data (callOnEndTest);
    • callOnEndTrain after the last epoch.

    Parameters:

    Name Type Description Default
    model Module

    The model to train. It should already be on config.DEVICE.

    		 required
    starting_epoch int

    Offset of the epoch counter. Used to resume a previous training. Defaults to 0.

    		 0

    Raises:

    Type Description
    Exception

    if no training data was provided, or if config.OPTIMIZER is "custom" and optimizer was not set.

    ImplicitSurfaceTrainer(config)

    Bases: Trainer

    Training a neural implicit to approximate a shape as its zero level set. The loss functions and hyperparameters are adapted from [1] and [2]. Given a neural network \(f\), The method optimizes for four loss functions:

    \[\mathcal{L}_{\text{on}}[f] = \int_M |f(x)| dx\]
    \[\mathcal{L}_{\text{normal}}[f] = \int_M ||\nabla f(x) - n(x)||\;dx\]
    \[\mathcal{L}_{\text{eikonal}}[f] = \int_D (|| \nabla f(x)|| - 1)^2\;dx\]
    \[\mathbb{L}_{\text{out}}[f] = \int_D \exp(-\rho\,|f(x)|)\;dx\]

    This trainer assumes that the dataset is made of (points, normals) pairs which are sampled on the shape, for the evaluation of $\(\mathcal{L}_{\text{on}}\) and \(\mathcal{L}_{\text{normal}}\). The two other loss functions are evaluated for every batch at random positions in a [-1.5, 1.5]^d box.

    Note

    The forward_test_batch method is not implemented and does nothing.

    References

    [1] Implicit Neural Representations with Periodic Activation Functions, Sitzmann et al., 2020
    [2] Implicit Geometric Regularization for Learning Shapes, Gropp et al., 2020

    Attributes:

    Name Type Description
    rho float

    value of rho in the outside loss. Defaults to 100.
    weights dict

    dictionnary of weights that are associated with each loss function. Keys and default values are: - "on" : 700 - "out" : 60 - "normal": 10 - "eikonal" : 5

    Parameters:

    Name Type Description Default
    config TrainingConfig

    The training hyperparameters.

    		 required

    hKRTrainer(config, margin=0.01, lmbd=100.0, test_mode='sdf')

    Bases: Trainer

    Trainer minimizing the hinge-Kantorovitch-Rubinstein loss. For a Lipschitz model \(f\) and some binary labels \(y(x) \in \{-1, 1\}\), the hKR loss is defined as:

    \[\mathcal{L}_{hKR}(x) = -yf(x) + \lambda \max(0, m - yf(x)).\]
    Warning

    This trainer only yields valid result when used on a Lipschitz architecture.

    References

    [1] Achieving robustness in classification using optimal transport with hinge regularization, Serrurier et al, 2021
    [2] 1-Lipschitz Neural Distance Fields, Coiffier and Béthune, 2024

    Parameters:

    Name Type Description Default
    config TrainingConfig

    training configuration hyperparameters.

    		 required
    margin float

    margin (m) parameter for the hKR loss. Defaults to 1e-2.

    		 0.01
    lmbd float

    lambda parameter of the hKR loss. Defaults to 100..

    		 100.0
    test_mode str

    which loss to compute for test batches. Choices are [none, sdf, hkr]. Defaults to "sdf".

    		 'sdf'
