Positional Encodings

Positional encodings are fixed transformations applied to the input data before being fed into a neural network. They increase the model's accuracy by tackling low-frequency biases. When defining a neural model, simply use a IL.nn.Implicitequential object to add your encoding before your neural network. Note that the encoding size and the input dimension of the network should match:

# Add an encoding made of Fourier Features to a simple multi-layer perceptron
model = IL.nn.ImplicitSequential(
    RandomFourierEncoding(geometry,1000),
    MultiLayerPerceptron(1000, 128, 4)
)

FourierEncoding(input_dim, encoded_dim=10)

Bases: ImplicitModel

Positional encoding used in neural radiance fields. Maps the input \(x\) to

\[[\sin(x),\, \cos(x),\, \sin(4x),\, \cos(4x),\, ...,\, \sin(2^n\,x),\, \cos(2^n\,x)]\]

Parameters:

Name Type Description Default
input_dim int

dimension of the input points (usually 2 or 3).

 required
encoded_dim int

number of frequencies (i.e. half the size of the final encoded vector). Defaults to 10

HyperplaneEncoding(points, normals, trainable=False)

Bases: ImplicitModel

Encoding that considers points with normals sampled on the geometry and applies the signed distance to each corresponding hyperplanes:

\[x \mapsto \langle n, x-p \rangle\]

where \((p,n)\) are points and normals.

Parameters:

Name Type Description Default
points Tensor

the points to consider

 required
normals Tensor

the normals associated with each point. Will be normalized.

 required
trainable bool

whether the points and normals can be trained as model parameters. Defaults to False.

 False

RandomFourierEncoding(input_dim, encoded_dim, stdv=1.0)

Bases: ImplicitModel

Encodes a given position into different frequencies of trigonometric functions :

\[x \mapsto [\cos(2\pi b x), \sin(2 \pi b x)]\]

where \(b\) is sampled from a normal distribution of zero mean (and provided standard deviation)

Parameters:

Name Type Description Default
input_dim int

dimension of the input points (usually 2 or 3).

 required
encoded_dim int

number of frequencies (i.e. half the size of the final encoded vector. the tensor b will have shape (geometry.dim, 2*encoded_dim)

 required
stdv float

Standard variation of the normal distribution used to compute b. Defaults to 1..

 1.0

Raises:

Type Description
ValueError

Fails if the encoding size is not an even number.
References
  • Fourier Features Let Networks Learn High Frequency Functions in Low Dimensional Domains, Tancik et al. (2020) : https://arxiv.org/abs/2006.10739
  • https://github.com/jmclong/random-fourier-features-pytorch/tree/main

MultiResDenseGridEncoding(input_dim, domain=None, n_levels=4, n_features_per_level=2, base_resolution=16, finest_resolution=128, smooth=False)

Bases: ImplicitModel

Multiresolution encoding using dense grid of parameters.

The resolutions of the grids are determined as logarithmically increasing between the base resolution and the finest resolution. For instance, the defaults parameters generate 4 grids from resolutions 16 to 128, which generates grids of resolution 16, 32, 64 and 128.

Warning

The number of parameters can quickly blow up if large resolutions are used. The default finest_resolution of 128 already reaches in the millions. For better scaling, see the MultiResHashGridEncoding class.

 None

number of features per grid level. Defaults to 2.

 16

finest grid resolution. Defaults to 128.

 128

whether to consider a smoothstep interpolation instead of a linear one. Defaults to False.

MultiResHashGridEncoding(input_dim, domain=None, n_levels=16, n_features_per_level=2, log2_hashmap_size=15, base_resolution=16, finest_resolution=512)

Bases: ImplicitModel

Multi-resolution hash encoding from Nvidia's instant NGP project. Instead of considering dense grids, considers a fixed-size hashmap of feature values at each resolution, enabling higher resolution without exploding the parameter count.

References

[1] Instant Neural Graphics Primitives with a Multiresolution Hash Encoding, Müller et al., 2022
[2] https://nvlabs.github.io/instant-ngp
[3] https://github.com/Ending2015a/hash-grid-encoding/tree/master
